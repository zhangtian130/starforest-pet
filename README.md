# 成长小宠物 · 单 HTML + GitHub Pages

儿童电子宠物应用：11 种宠物、四阶段成长、264 个写实穿搭形象、写实家园、每日任务、宠物图鉴、成长地图、家长 PIN 和跨手机数据恢复码。

## 文件

`index.html` 是完整应用，图片、样式和程序均在其中；可以离线单独打开，也可以由 GitHub Pages 直接托管。无需安装、构建或依赖第三方图片链接。`.nojekyll` 用于让 Pages 直接发布静态文件。

## 发布（最少步骤）

1. 创建自己的 GitHub 仓库；使用公开仓库时，应用源文件对外公开，但不会自动公开本地宠物存档。
2. 把 `index.html` 和 `.nojekyll` 上传到仓库根目录，提交到 `main` 分支。不要直接把 ZIP 文件作为网站上传，先解压。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment → Source** 选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，保存。
5. 等待 GitHub 显示发布完成，再使用其提供的网址。网址通常为 `https://你的用户名.github.io/仓库名/`，实际地址以 GitHub 后台为准。

官方说明：[发布来源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)、[创建 Pages 网站](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。

## 跨手机恢复

### 原手机

1. 打开此新版 HTML 或网页版，进入家长区并输入 PIN。
2. 点 **生成最新数据恢复码**。
3. 复制完整恢复码，或下载恢复码文本，私下保存在自己的设备或传给自己的另一部手机。

### 新手机

1. 打开同一个 GitHub Pages 网址。
2. 首次进入家长区，设置该手机的 6 位数字 PIN，并保存家长 PIN 恢复码。
3. 在 **数据恢复码** 区域粘贴原手机的完整数据恢复码，点 **检查并恢复**。
4. 对比存档时间和星星数量，确认后恢复宠物、任务、成长、星星、穿搭、家园与记录。

**数据恢复码是存档快照，不是自动云同步。** 在任一手机产生新进度后，需要重新生成并传递最新恢复码。旧恢复码不会自动更新；两部手机同时使用会形成各自的存档，不会自动合并。

## 两种恢复码不要混淆

- **数据恢复码**：以 `SFP1.` 开头，携带完整宠物数据，长度随存档变化；可跨手机恢复，不包含 PIN 或云端账号。带完整性校验，不是加密保险箱，请私下保管。
- **家长 PIN 恢复码**：用于当前浏览器忘记 PIN 时重设，不携带宠物数据，不能用于跨设备找回存档。

## 从旧版迁移

如果原浏览器已经使用旧 HTML，只需用新版替换原文件并保持原位置。若新版读取不到原存档，在旧版家长区导出 JSON，再导入新版，之后即可生成数据恢复码。

本地 HTML、GitHub Pages、不同网址、不同手机和不同浏览器的本地存储相互独立。PIN 单独保存在每个浏览器中，不随宠物数据恢复。

## 其他

- 未完成任务不惩罚宠物；成长必须主动花星星。
- JSON 导出、导入、恢复前撤回副本和可选 Supabase 云同步保留。
- 使用新版 Safari、Chrome 或 Edge；压缩恢复码需要浏览器支持 gzip 解压。不支持时可用 JSON 备份恢复。
- 请不要把自己生成的数据恢复码、存档备份、PIN、恢复码或云服务密钥提交进 GitHub 仓库。
- 首次加载需下载含内置图片的完整 HTML，约 16.7 MB，之后浏览器可利用缓存。
